# 🧮 Calculator Website

## 📌 Overview

This project was developed as part of my Web Development Internship at CodeSoft. The objective of this task was to create a fully functional and responsive calculator capable of performing basic arithmetic operations with an intuitive and user-friendly interface.

The project demonstrates the implementation of JavaScript logic along with modern HTML and CSS design principles to build an interactive web application. Similar CodeSoft web development internship repositories commonly include a calculator website as Task 3.

## ✨ Features

* Addition, Subtraction, Multiplication, and Division
* Clear (AC) Functionality
* Responsive User Interface
* Real-Time Calculation
* Clean and Modern Design
* Mobile-Friendly Layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Project Objective

The primary objective of this project was to strengthen JavaScript fundamentals by implementing calculator logic, handling user inputs, and creating an interactive web application with a responsive design.
