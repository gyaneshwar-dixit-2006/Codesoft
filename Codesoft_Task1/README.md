# 💼 Personal Portfolio Website

## 📌 Overview

This project was developed as part of my Web Development Internship at CodeSoft. It is a responsive personal portfolio website designed to showcase my skills, projects, achievements, and contact information in a professional manner.

The website provides visitors with an overview of my background, technical expertise, and work while maintaining a clean and modern user interface.

## ✨ Features

* Responsive Design
* Modern User Interface
* About Me Section
* Skills Showcase
* Projects Section
* Contact Information
* Smooth Navigation
* Mobile-Friendly Layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Project Objective

The objective of this project was to create a professional portfolio website that highlights personal information, technical skills, and completed projects while applying modern web development practices.

## 📚 Learning Outcomes

Through this project, I improved my understanding of:

* Frontend Web Development
* Responsive Web Design
* UI/UX Principles
* JavaScript Functionality
* Git & GitHub Version Control
